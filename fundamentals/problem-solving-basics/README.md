## A Simple Workflow

1. Understand what the problem asks.
2. Check the input constraints.
3. Start with the simplest correct approach.
4. Dry-run your solution with a small example.
5. Test edge cases.
6. Analyze time and space complexity.
7. Optimize if necessary.
