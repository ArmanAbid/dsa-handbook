
# Bit Manipulation

Bit manipulation works directly with the binary bits of integers. Can simplify some operations and is frequently used in algorithms, masks, and XOR-based problems.

## Learning Goals

- Understand how integers are represented in binary.
- Use bitwise AND, OR, XOR, NOT, and shifts.
- Set, clear, toggle, and check individual bits.
- Count set bits efficiently.
- Identify typical XOR patterns in coding problems.
