# Fundamentals

This section contains the fundamental concepts that are essential to understand Data Structures and Algorithms (DSA). It is important to understand the execution of programs, how to analyze their efficiency, and how to reason about their correctness before learning individual data structures and algorithms.

The aim is to create a solid base for the easier and systematic solution of DSA problems.

## Recommended Learning Order

For beginners, the following order provides a useful progression:

1. **Problem-Solving Basics** — Learn how to approach a problem before writing code.
2. **Complexity Analysis** — Understand how to evaluate algorithm efficiency.
3. **Mathematics** — Build the mathematical foundation used in many DSA problems.
4. **Number Representation** — Learn how numeric values are represented and where arithmetic can go wrong.
5. **Memory and References** — Know the way data is stored and retrieved in various languages of programmin
6. **Recursion** — Solve problems by reducing them to smaller instances of the same problem.
7. **Bit Manipulation** — Understand low-level operations and techniques for specialized problems.

These topics can be reviewed as often as when an algorithm introduces a new concept.

## Supported Languages

This handbook is intended to support learning DSA across multiple programming languages:

- C++
- Python
- TypeScript

The concepts are applicable to all languages, but the syntax, memory usage, and language features may vary.
