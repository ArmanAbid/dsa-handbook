# Number Representation

Computers represent numbers using finite amounts of memory. Knowing these representations can avoid overflow, precision errors and unexpected results.

## Learning Goals

- Understand how integer types represent numbers.
- Understand integer overflow and integer underflow.
- Be familiar with signed and unsigned arithmetic.
- Know why floating-point numbers can be imprecise.
- Choose appropriate types and comparisons for numerical problems.
