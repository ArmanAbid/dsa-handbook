
# Memory and References

Understanding memory helps explain how variables store values, how objects are accessed, and why changing one variable can sometimes affect another.

## Topics

1. [Stack and Heap](stack-and-heap.md)
2. [Value vs Reference](value-vs-reference.md)
3. [Pointers](pointers.md)
4. [References in C++](references-in-cpp.md)
5. [Memory Allocation](memory-allocation.md)
6. [Shallow vs Deep Copy](shallow-vs-deep-copy.md)

## Learning Goals

- Understand the basic roles of stack and heap memory.
- Distinguish values, references, and pointers.
- Understand how objects can be shared between variables.
- Recognize memory leaks, dangling pointers, and invalid accesses.
- Understand shallow and deep copying.
