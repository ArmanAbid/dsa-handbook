# Mathematics for DSA

Common mathematical topics in Data Structures, Algorithms and Competitive Programming.

## Topics

1. [Basic Math Operations](basic-math-operations.md)
2. [Divisibility and Prime Numbers](divisibility-and-primes.md)
3. [GCD and LCM](gcd-and-lcm.md)
4. [Logarithms](logarithms.md)
5. [Powers and Exponents](powers-and-exponents.md)
6. [Modular Arithmetic](modular-arithmetic.md)

## Learning Goals

Upon studying these topics, you should be able to perform basic mathematical operations, know prime numbers, compute greatest common divisors and least common multiples, know about logarithms, work with powers, and solve simple problems in modular arithmetic.
