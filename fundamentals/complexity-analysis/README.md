# Complexity Analysis

Complexity analysis is a method that helps us to estimate the time and space requirements of an algorithm as the size of the input increases.

## Files

- [Time Complexity](time-complexity.md) — the growth of the amount of work.
- [Space Complexity](space-complexity.md) — how additional memory requirements increase.
- [Complexity Classes](complexity-classes.md) — Common growth rates, from constant to exponential.
- [Analyzing Code](analyzing-code.md) — a practical way to analyze loops and simple code.

## The main idea

Growth is typically described in terms of the size of the input, `n`. We are interested in the growth of this as n increases, not the number of seconds on a particular computer.
